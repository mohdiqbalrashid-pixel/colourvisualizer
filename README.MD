# Jotun Colour Visualizer — Prototype

A Streamlit prototype for consultant-assisted wall colour visualisation.

## Current features
- Upload room photo
- Select wall area using sliders
- Apply selected Jotun colour
- Preserve light and shadow using LAB colour processing
- Preview before/after
- Download recoloured image

## Next features
- Brush-based wall selection
- AI-assisted wall detection
- Jotun colour database integration
- Product recommendation
- Consultant export summary
